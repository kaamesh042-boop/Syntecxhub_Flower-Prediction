🌸 Flower Classification Dashboard

A professional, interactive machine learning dashboard that demonstrates flower species classification using the renowned Iris dataset. This project combines data analysis, machine learning, and modern web-based visualization techniques to provide an intuitive platform for exploring classification models and understanding predictive analytics.

Overview

The Flower Classification Dashboard is a browser-based application designed to classify Iris flowers into three species—Setosa, Versicolor, and Virginica—using machine learning algorithms implemented entirely in JavaScript. The project showcases the complete machine learning pipeline, including data exploration, model training, evaluation, visualization, and real-time prediction.

Application Modules
1. Exploratory Data Analysis

Provides statistical insights into the dataset, including feature distributions, class balance, and summary metrics.

2. Feature Visualization

Allows users to explore relationships between flower measurements through interactive scatter plots.

3. Model Comparison

Evaluates and compares the performance of Logistic Regression and Decision Tree classifiers.

4. Confusion Matrix Analysis

Visualizes prediction accuracy and classification errors for each model.

5. Prediction Console

Enables users to input custom flower measurements and receive instant species predictions.
